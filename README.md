# Tetris
Proyecto del juego Tetris desarrollado en TypeScript utilizando programación orientada a objetos.

    # Lenguajes y extensiones utilizados

- TypeScript
- Node.js
- Vitest
- @vitest/coverage-v8
- Git y GitHub

        # Instalación

`bash
npm install

// Para ejecutar los test

    npm run test

// Si aparece error de permiso en powershell usar:

    npm.cmd run test

para la cobertura del código 

    npx vitest run --coverage
